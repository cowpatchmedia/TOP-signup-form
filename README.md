A simple sign up form for TOP. Styling the form using HTML and CSS was the main point of this project.
I didn't end up using JSS though I could have for more control over the error messages. 
I used some regex for the telephone number but could definitely add more for better validation. 
The project doesn't push data to anywhere, is more of a CSS/HTML challenge.
Overall, I noticed I am getting better at flexboxes which were used extensively in this project.
